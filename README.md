# בת מצווה — תיק העבודה

תיק העבודה לתכנון ערב בת המצווה. הקונספט כבר גובש; כאן הופכים אותו לביצוע.

## הקונספט בשורה אחת
היא נכנסת לחיוב — והיא חוליה בשרשרת. **וזה אותו דבר.**

2. **ערך / מידה** קרובים אליה או שרוצים להדגיש — החוט שמחבר בין הקיר, הרגע שלה ובית המדרש.

עד שאלה מוכרעים, הטקסטים ב-`04` נשארים עם מקומות שמורים (`[שם]`, `[ערך]`).
