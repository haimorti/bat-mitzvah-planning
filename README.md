# אלומה נכנסת לחיוב — תיק העבודה

> ## אלומה נכנסת לחיוב
> *כותרת הערב. לְחיוב — כי מהיום היא מְצֻווה. וּבְחיוב — כי ככה היא בוחרת להיכנס.*

תיק העבודה לתכנון ערב בת המצווה של **אלומה**. הקונספט כבר גובש; כאן הופכים אותו לביצוע.

## הקונספט בשורה אחת
היא נכנסת לחיוב — והיא חוליה בשרשרת. **וזה אותו דבר.**

## מסגרת האירוע
אולם קטן בבית כנסת · משפחה קרובה · **~50 איש** · אופי צנוע ומשפחתי.

## קלטים חוסמים

**הוכרעו ✅**
1. **שם:** אלומה קדוש.
2. **ערך מרכזי:** *חיוביות — להיכנס בחיוב.* החוט שמחבר בין הקיר, הרגע שלה ובית המדרש (משחק המילים חיוב = מחויבות + חיוביות).

**עוד פתוחים (לוגיסטיים)** — ראו שלב 0 ב-[`02`](02-תוכנית-עבודה.md): תאריך+מיקום, מספר אורחים/שולחנות, מספר וגילאי הילדים.
